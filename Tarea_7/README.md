# Base de Conocimiento

## Incidencia

### Sin Conexión a Internet (Wi-Fi/LAN)

---

## ¿A quién aplica?

Usuarios de equipos con conexión mediante:

- Wi-Fi
- Cable de red (LAN)

---

## Síntomas del error

- Imposibilidad total de navegar por Internet.
- Mensaje del sistema: **"Sin acceso a Internet"**.
- Las aplicaciones locales no logran conectarse.
- El ícono de red muestra una advertencia o una **X**.

---

## Causas probables

- Wi-Fi desactivado o interruptor físico apagado.
- Cable de red (LAN) desconectado o dañado.
- Dirección IP local no asignada correctamente.
- Adaptador de red deshabilitado por el sistema.
- Problema temporal en el módem o router.

---

## Procedimiento de solución

1. Verificar que el Wi-Fi esté activado o que el cable de red esté correctamente conectado.
2. Confirmar que el equipo esté conectado a la red correcta.
3. Reiniciar el módem o router:
   - Desconectarlo durante 10 segundos.
   - Volver a conectarlo.
   - Esperar aproximadamente 2 minutos.
4. Reiniciar el equipo.
5. Verificar que el adaptador de red esté habilitado desde el Administrador de dispositivos.
6. Ejecutar el Solucionador de problemas de red de Windows si el problema continúa.

---

## Validación

La incidencia se considera resuelta cuando:

- El navegador carga páginas correctamente.
- El comando de prueba responde exitosamente.
- Los aplicativos corporativos recuperan la conexión.

---

## Plan de escalamiento

Si el problema continúa después de realizar todos los pasos anteriores:

- Escalar el caso al equipo de Infraestructura o Redes.
- Adjuntar capturas del error o de la terminal.
- Indicar si el problema afecta a un solo usuario o a varios.

---

## Nota de seguridad

> No comparta contraseñas de la red corporativa ni modifique configuraciones avanzadas del sistema sin autorización del área de soporte técnico.

---

## Herramienta utilizada

**Terminal / Símbolo del sistema (Windows)**

Se recomienda comprobar la conectividad abriendo una página web o ejecutando pruebas de conexión desde la terminal.
